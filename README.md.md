# Prakriti Bhandari — Portfolio

My personal portfolio site, showcasing deployed AI/ML projects with live demos, source code, and case studies.

**Live site:** https://prakritibhandari07.github.io/prakriti-portfolio/

## Pages

- **Home** (`index.html`) — one-line intro and featured projects
- **Projects** (`projects.html`) — all 6 projects with descriptions, tags, and links to live demos / APIs / source code
- **About** (`about.html`) — background, skills, and what I'm currently learning
- **Contact** (`contact.html`) — email, LinkedIn, and GitHub

## Stack

Plain HTML/CSS, no framework or build step. Hosted for free on GitHub Pages.

I chose this stack deliberately over a static site generator (e.g. Jekyll) or a no-code builder (e.g. Framer): it matches my current skill level, requires no new tooling to maintain, and is fully within my control since it's just files in a repo with no third-party platform dependency.

## Design System

- **Font:** Inter (Google Fonts)
- **Palette:** Text `#1A1A1A` · Background `#FAFAFA` · Accent `#3B6DFF`
- **Style:** Calm, minimal, generous whitespace — the goal is for real project screenshots and results to be the most visually interesting thing on the page, not decoration.

## Running Locally

No build step required. Clone the repo and open `index.html` directly in a browser, or serve it with any static file server, e.g.:

```bash
python -m http.server
```

Then visit `http://localhost:8000`.
